# 连续原位编辑

用户确认的目标：原位编辑中可以连续修改多处，不要求划选文字，不在切换段落时提示保存；整篇文档作为一次编辑会话。

- 每个标签保存独立草稿集合，条目包含原文、修改文本及正文 DOM 路径。同一位置重复编辑更新同一条，回到原文则移除该条。
- 顶部保存和快捷键统一提交正文全部改动及已暂存批注，一次写盘、一条正文修改记录。
- 所有源补丁基于同一份原文解析并验证，位置重叠或无法映射时不做部分写入。
- 退出原位编辑或切换编辑方式时，提供保存并退出、不保存、继续编辑；写盘失败保留完整草稿。切换标签保留草稿，刷新与关闭仍执行未保存保护。
- HTML 隔离预览通过消息传送草稿集合；保留静态源定位和文件冲突检测，不将整个页面序列化覆盖原文件。
- 临时隐藏编辑区域的批注装饰，避免高亮包装节点阻碍正常编辑；退出后恢复显示。

验证：MD/HTML 多处编辑及回头改写、批量保存、退出三选、标签恢复、另存、写盘失败与外部冲突；使用临时文件和单个测试窗口。
